# Spending Analysis Dashboard

Next.js personal finance dashboard for exploring spending patterns, budget data, and category-level behavior.

## What This Shows

- Building a clean analytical interface around real personal finance workflows
- Translating budget data into more useful views for review and decision-making
- Practical use of TypeScript, Next.js, and modern dashboard UI patterns

## Tech Stack

- Next.js
- TypeScript
- React
- Vercel
